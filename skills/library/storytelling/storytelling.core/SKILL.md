# Core Storytelling

- Establish one clear central idea and a concrete viewer promise.
- Open with a specific question, surprising fact, vivid image or consequential claim.
- Build in a logical progression: setup, development, turn, payoff.
- Every scene must advance the idea, reveal evidence or create a meaningful emotional beat.
- Avoid generic filler, repeated claims and unsupported certainty.
- End with a memorable conclusion that resolves the opening promise.
