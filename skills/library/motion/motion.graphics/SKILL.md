# Motion Graphics

- Use motion to explain relationships, sequence, scale or change.
- Establish hierarchy before animation: one primary message, supporting labels, restrained decoration.
- Animate with consistent easing and clear start/end states.
- Keep labels attached to the objects they describe; avoid collisions and edge clipping.
- Use charts only when values and comparisons are supported by source data.
- Prefer reusable scene components over one-off visual hacks.
