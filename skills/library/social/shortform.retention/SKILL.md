# Short-form Retention

- Make the first 1–3 seconds communicate a specific reason to keep watching.
- Prefer one idea per beat; remove setup that does not change understanding.
- Alternate visual modes intentionally: footage, graphic, close-up, text, diagram.
- Use pattern interrupts only when they reinforce meaning, not as random noise.
- Build toward a reveal, answer or payoff; do not end abruptly.
- Keep captions concise, readable and inside platform-safe areas.
